# P0 试跑报告（2026-11-17，只读）

## 一、样本与方法

- 样本：24 道，来自 211 道“解析‘故选’与答案不一致”批次；14 道单选 + 10 道多选，`qc_error`/`warn` 混合。
- 分组：8 批 × 3 道，8 路并发，两遍串行；每个子代理只读自己的批次文件，不查库、不看现答案。
- 第一遍提示词：先逐题分析，再给答案；
- 第二遍提示词：先给第一直觉答案，再逐项自检（题干残缺/缺图、选项匹配、答案唯一性）。
- 比对：答案归一化（选择题按字母去重排序）后比较两遍，再与现答案比较。

## 二、结果

| 项 | 数量 |
|---|---:|
| 两遍一致 | 23 / 24 |
| 两遍一致且与现答案一致 | 23 / 24 |
| 两遍一致但与现答案不同 | 0 / 24 |
| 两遍分歧 | 1 / 24 |

### 关键题

- **336203（分歧，标 uncertain）**：现答案 D；第一遍 B（GB18030 常用汉字 100 个 = 200 字节），第二遍 D（文件在硬盘上按扇区/簇分配，实际占用 512 字节）。题干“所占硬盘的空间”有歧义，按共识不自动改，进人工清单。
- **334586（低置信 + 缺图）**：两遍都选 D，但题干引用的主板示意图缺失，第一遍 confidence=low、第二遍 medium；答案暂不改，进 P1 缺图清单。
- **335428、342969（题型疑似标错）**：两遍答案与现答案一致（D、B），但 `question_type=2` 多选只有一个正确项；进 P0 的“13 道多选单字母”批次，改单选而不是改答案。
- **其余 20 道**：两遍答案一致且与现答案一致；其中多道解析与答案矛盾，例如：
  - 335432：答案 B,C,D，解析写 B,C；
  - 335569：答案 A,B,C,D，解析写 B,C,D；
  - 335738 / 335780：答案 A,B,C，解析写 A,C,D；
  - 336081：答案 B，解析写 A；
  - 336240：答案 D，解析写 A。

## 三、结论

1. **211 道“故选”矛盾主要是解析写错，不是答案错**。试跑 24 道中 0 道确认需要改答案，1 道歧义；全量批次的主要工作是按确认答案重写解析。
2. **双遍盲答流程可用**：8 路并发、两遍串行、每个子代理 3 道，24 道约 2–3 分钟完成；答案一致率 23/24。
3. **还需要补一步**：解析重写提示词的试跑。当前两遍只验证了答案，没有验证重写后的解析质量；建议先用 5 道试跑“确认答案后写 1–2 句解析”的提示词，再全量 211。
4. 试跑还顺带发现 2 道题型标错、1 道缺图、1 道题干歧义，说明同一批题里混有 P1/P3 问题，落库时要按类型拆开处理。

## 四、下一步

1. 用 5 道试跑“解析重写”提示词，确认长度、风格、正确性。
2. 全量 211 道：答案双遍盲答 → 解析重写 → 生成 dry-run CSV。
3. 你确认 CSV 后，按 25 道一批落库；每批备份 + 断言，Claude 第三遍抽检 10%，高风险题全列。
4. 336203 进人工清单；334586 进 P1 缺图清单；335428、342969 进 13 道多选单字母批次。
