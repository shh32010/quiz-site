# P0-211 dry-run 汇总（2026-11-17，未写库）

## 一、范围与方法

- 范围：211 道“解析‘故选’与答案不一致”的可练题。
- 方法：Claude 两遍独立盲答（8 路并发、两遍串行、每个子代理 10 道；第一遍先分析再作答，第二遍先直觉再自检）。
- 仲裁：两遍一致且无源资料冲突才改；分歧、源资料冲突、题干缺图/截断/泄漏标记的题进人工清单。
- 源资料抽查：本地 Markdown 提取稿 + `知识库_v2` 原始 JSON。
