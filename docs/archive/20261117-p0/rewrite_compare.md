## 335432（2，答案 B,C,D）
- 题干：关于 PC 机中的显卡、声卡和网卡, 下列叙述错误的是 ( )
- 旧解析：A 三者均为 I/O 控制器、D 均可集成（正确）；B「只有独立插卡」、C「相同 I/O 接口」错误，故选 BC。
- A（ok，105 字）：错误的是 B、C、D。显卡、声卡、网卡都属于输入输出控制器，A 正确；三者除独立插卡外也都可集成在主板芯片组上，B 错；显卡与网卡使用的接口并不相同，C 错；集成显卡一般并入北桥或处理器，而非南桥芯片，D 错。
- B（ok，86 字）：显卡、声卡、网卡都是 I/O 控制器，A 正确；三者接口标准不同，C 错；并非只能做成独立插卡，B 错；显卡控制器在北桥或 CPU 内，不集成到南桥，D 错。故选 BCD。

## 335569（2，答案 A,B,C,D）
- 题干：下列关于微处理器的叙述，正确的是_________。
- 旧解析：Core i5 多核、Intel 四大系列、凌动用于移动终端（BCD 正确），故选 BCD。
- A（ok，97 字）：四项均正确。Core i3/i5/i7 系列都是 64 位微处理器，i5 为多内核设计；Intel 微处理器主流有奔腾、酷睿、赛扬、凌动四大系列；凌动功耗低，多用于上网本和移动终端，故四项全选。
- B（ok，98 字）：Core i3/i5/i7 都是 64 位多核处理器，A、B 正确；Intel 主流芯片分为奔腾、酷睿、赛扬、凌动四大系列，C 正确；凌动功耗低，多用于上网本和移动终端，D 正确。故选 ABCD。

## 335738（2，答案 A,B,C）
- 题干：下列关于微电子技术的叙述，正确的是 ( )
- 旧解析：Moore 定律、PC 芯片均超大规模、IC 以微电子技术为核心（ACD 正确），故选 ACD。
- A（ok，116 字）：正确的是 A、B、C。摩尔定律即单块集成电路的集成度平均每 18～24 个月翻一番；现代集成电路材料以硅为主，也用砷化镓等化合物半导体；PC 微处理器属于超大规模和极大规模集成电路。D 把关系说反了，应是微电子技术以集成电路为核心。
- B（ok，123 字）：Moore 定律指出集成度平均每 18~24 个月翻一番，A 对；半导体材料以硅为主，也可用砷化镓等化合物半导体，B 对；现代 PC 微处理器均属超大规模和极大规模集成电路，C 对；D 把关系说反了，应是微电子技术以集成电路为核心。故选 ABC。

## 336081（1，答案 B）
- 题干：微电子技术是信息技术领域的关键技术，它以集成电路（IC）为核心。在下列有关叙述中，错误是的（）
- 旧解析：现代 CPU 集成度已达数百亿个电子元件（不止数千万），A 说法错误；B 的 Moore 定律应是 18~24 个月翻一番。故选 A。
- A（ok，111 字）：错误的是 B。摩尔定律指出单块集成电路的集成度平均每 18～24 个月翻一番，而非每半年翻一番。A 中 CPU 集成度可达数千万个元件，现已更高；C 的制造工序繁杂、D 的非接触式 IC 卡靠电磁感应传输数据，均符合事实。
- B（ok，72 字）：Moore 定律指出集成度平均每 18~24 个月翻一番，而不是每半年，B 明显错误；A、C、D 的叙述都符合集成电路实际和教材说法，故选 B。

## 336240（1，答案 D）
- 题干：关于PC机主板上的CMOS芯片，下面说法中正确的是（ ）（2.0）
- 旧解析：判断两台主机是否处于同一网段的一般方法是将两台计算机各自的IP地址与子网掩码进行AND运算后，如果得出的结果是相同的，则说明这两台计算机是处于同一个网段上的。题中172.16.163.40与子网掩码255.255.0.0进行AND运算后，结果为172.16.0.0。A选项172.16.1.1与子网掩码进行AND运算后，结果为172.16.0.0，B选项190.168.1.1与子网掩码进行AND运算后，结果为190.168.0.0，C选项190.168.1.1与子网掩码进行AND运算后，结果为190.168.0.0，D选项172.1.1.1与子网掩码进行AND运算后，结果为172.1.0.0，故选A。
- A（ok，119 字）：正确的是 D。CMOS 芯片是低功耗静态存储器，保存 BIOS 设置和实时时钟数据，需电池供电，否则数据丢失。A 的加电自检由 BIOS 完成；B 错在它是随机存储器而非只读存储器；C 的 BIOS 程序存于 ROM，不在 CMOS 里。
- B（ok，110 字）：CMOS 芯片是低功耗 RAM，用于存放 BIOS 设置参数，需主板电池供电，断电后数据丢失，D 正确；自检由 BIOS 完成、BIOS 程序存于 ROM 中，A、B、C 都把 CMOS 与 BIOS 混淆了。故选 D。
