# 题库同类问题全库扫描（2026-11-17，只读）

> 目的：回答“其他题目是否也有这次反馈里的同类问题”。
> 口径：`t_question` 中 `not deleted and review_status='ok'` 的可练题池（44,455 道，修复前）。
> 所有查询均为只读，未改库。

## 一、结论

同类问题确实存在，且可分为三类：

1. **答案/解析正确性**：解析“故选”与答案不一致 212 道；填空/综合但答案是字母 54 道；多选但答案只有一个字母 14 道。
2. **可用性/排版**：图示题缺配图 280 道；填空空线残缺 70 道；题型 4/5 仍带选项 192 道。
3. **可批量清洗的机械问题**：选项 HTML 实体 513 道；解析以冒号开头 488 道；判断题“（ ）”前缀 221 道；OCR 残片开头 16 道；选项 LaTeX 145/337 道。

## 三、重要口径说明

### 1. 280 道缺图题是“真的没有图”

对 280 道全部检查了 `t_text_content.content`，**没有一道包含 `/qimg/` 图片路径**，不是 `has_image` 标记错误。
其中一部分题干只是泛泛提到“图”（如 DFD 图），不一定真的需要配图；实际不可用题数会低于 280，需要逐题判断。

### 2. 212 道“故选”不一致是候选，不是最终结论

正则只抓“故选 X”，可能命中：
- 解析先讨论错误选项、最后才给出正确项；
- 一道题包含多个小问；
- 解析本身写错或答案字段被改过。

但抽样 20 道中多数是真实矛盾（如 334586 答案 D、解析写 B；335428 答案 D、解析写 AB），值得优先逐题复核。

### 3. 5,026 组“重复”大多是误报

去标点/空格后，大量题目共享“下列叙述中正确的是”“以下叙述中错误的是”这类通用题干，但选项不同，不是重复题。
本次 337377 簇属于“同选项 + 近题干”的真重复，**现有的精确去重（85 组 + 22 组）没有覆盖这种变体**。下一步应使用：
- `option_json` 完全相同或高度相似；
- 题干 trigram 相似度（如 `similarity(stem_a, stem_b) > 0.75`）；
- 同题型、答案一致或答案冲突分组；
再做一轮近重复簇审计。

### 4. 54 道“填空题答案是字母”要分开看

- 一部分是 `question_type=5`，选项直接写在题干里（如 334900 的题干包含 A–D），实际是单选题被标成综合题；
- 一部分是 `question_type=4`，`correct` 只剩一个字母（如 338179 答案 B，但题干问“转换成____程序”，正确答案应是“机器语言/目标程序”），属于答案损坏。
这类会影响判分，优先级高于排版问题。

## 四、建议处理顺序

| 优先级 | 事项 | 规模 | 方式 |
|---|---|---:|---|

| P0 | 解析“故选”与答案不一致 | 212 | 逐题复核，必要时用 LLM 辅助 |
| P1 | 图示题缺配图 | 280 | 逐题判断：补图 / 转文字 / 隔离 |
| P1 | 填空空线残缺 | 70 | 按 `blank_count` 规范空线 |
| P2 | 选项 HTML 实体 | 513 | 批量解码，逐批抽检 |
| P2 | 解析开头冒号 | 488 | 批量去前缀 |
| P2 | 判断题“（ ）”前缀 | 221 | 批量去前缀 |
| P2 | OCR 残片开头 | 16 | 逐题清理 |

| P3 | 近重复簇 | 待审计 | 用选项+题干相似度重跑 |
